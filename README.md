# Mana Endurance Planner

An interactive calculator for World of Warcraft casters. Enter your Spirit, Intellect, gear MP5, spell power and mana cost reduction to see:

- how long you can chain-cast before going OOM
- your DPS over a fight of any length
- which stat is worth the most for your character right now

Live page: https://tiqqletest-cloud.github.io/manaendurance/

Everything runs in the browser from a single `index.html` file.
